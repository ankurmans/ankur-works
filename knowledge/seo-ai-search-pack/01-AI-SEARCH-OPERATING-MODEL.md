# AI Search — Public-Safe Operating Model

AI Search is best treated as SEO with a different last mile: systems may retrieve documents, extract passages, synthesise answers, cite sources and recommend entities.

## Four layers
1. Model layer — what is already baked into training.
2. Retrieval layer — what can be found/fetched now.
3. Answer layer — what retrieved material gets synthesised/cited.
4. Recommendation layer — which brands/entities get named.

## Two games
Slow game: training/entity associations, broad corroboration, durable co-occurrence.
Fast game: retrieval/grounding, rankings, crawlability, passages, freshness, authority, source inclusion.

## Practical framework
- Build a commercial query/prompt universe.
- Measure mention/citation/competitor/source overlap.
- Map recurring cited sources.
- Improve retrievability: explicit entities, direct passages, clean structure, crawl/indexability.
- Add information gain: data, tests, benchmarks, tools, first-hand evidence.
- Strengthen third-party corroboration and remeasure repeatedly.

## Public positions
- One chatbot screenshot is not measurement.
- Schema is identity/disambiguation hygiene, not a magic citation switch.
- Ranking #1 does not guarantee citation/recommendation.
- AI Search does not make classic SEO irrelevant; retrieval still matters.
