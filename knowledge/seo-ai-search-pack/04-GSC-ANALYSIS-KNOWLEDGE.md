# Search Console Analysis Knowledge

GSC is strongest for clicks, impressions, CTR, average position, queries, pages, countries, devices, search appearance and time trends. It is not revenue attribution by itself.

## Comparisons
Prefer matched windows:
- last 28 vs previous 28
- last 28 vs same period YoY
- last 90 vs previous 90
- post-intervention vs matched pre-intervention

## Always segment
- brand vs non-brand
- commercial vs informational
- query cluster
- page type
- device/country where material

## Richest unit
Store date × query × page, then optionally country/device/search appearance.

## Proof hierarchy
1. clicks
2. non-brand clicks
3. commercial-intent clicks
4. qualified landing-page growth
5. query breadth
6. impressions
7. position
8. CTR

## Strong proof phrasing
Prefer raw numbers plus multiple:
"38 → 402 clicks across matched 28-day windows (10.6x)"
over a naked "+958%".

## Tiny-base guardrail
Do not headline 10x from 1→10. For strong public multiple claims, require a meaningful baseline and show the raw values.
